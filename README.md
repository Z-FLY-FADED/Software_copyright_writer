# Software Copyright Writer

**简体中文** · [English](README.en.md)

`Software_copyright_writer` 是一个面向中文软件著作权材料编写的 Codex Skill。它帮助 Codex 根据源代码、项目文档、参考软著文档和 Word 模板，生成规范的《软件设计说明书》《软件使用说明书》《用户操作手册》等材料，并可按需要补充架构图、流程图、模块表、环境表和测试用例表。

## 适用场景

- 根据完整源码目录生成软件著作权说明书。
- 根据已有软著样稿迁移结构和表达风格，但重写为新软件内容。
- 根据 Word 模板排版生成 `.docx` 文档。
- 为软著申报补充系统架构、功能模块、运行环境、接口、数据处理流程、测试验证和维护升级说明。
- 根据代码结构生成用户使用手册或操作说明。
- 对软著文档进行补写、扩写、润色、结构优化和合规检查。

## 目录结构

```text
Software_copyright_writer/
├─ SKILL.md             # Codex 使用的技能说明
├─ README.md            # 技能概览与维护说明
├─ 使用手册.md          # 面向使用者的详细操作指南
├─ assets/              # 可放置 Word 模板、封面素材等输出资源
├─ references/          # 可放置参考软著文档、规范说明、样例材料
└─ scripts/             # 可放置可复用的分析、转换、渲染脚本
```

## 推荐输入

| 输入 | 说明 |
|---|---|
| 源代码目录 | 软件源码、配置文件、依赖文件、脚本、数据库结构、前后端文件等 |
| 参考软著 | 已完成的软著说明书或使用手册，用于参考章节结构与写作风格 |
| Word 模板 | `.docx` 格式模板，用于保持封面、页眉页脚、字体、标题和页码样式 |
| 软件信息 | 软件名称、版本号、开发语言、运行环境、适用对象、部署方式等 |
| 输出要求 | 文档类型、页数、是否导出 PDF、是否生成图表、输出路径 |

## 快速使用

```text
请使用 Software_copyright_writer skill，根据以下材料生成一份软件著作权说明书：
源码路径：[源码目录]
参考软著路径：[参考资料目录]
模板路径：[Word 模板路径]
输出路径：[输出目录]

要求：
1. 文档类型为软件设计说明书，正文不少于 20 页；
2. 内容必须基于源码真实结构，不虚构不存在的核心功能；
3. 参考已有软著的结构和表达方式，但不得直接复制；
4. 包含总体架构图、功能结构图、主程序流程图、数据处理流程图；
5. 包含运行环境表、功能模块表、源代码文件说明表、核心函数表和测试用例表；
6. 输出 Word 文档；如条件允许，同时导出 PDF。
```

## 维护原则

- `SKILL.md` 保持精炼，只保留触发条件、核心流程和关键约束。
- 详细示例、提示词和人工使用说明放在 `使用手册.md`。
- 参考样稿放入 `references/`，但生成新文档时只参考结构和风格，不直接复制正文。
- 模板、封面图、样式文件等放入 `assets/`。
- 重复性强、容易出错的代码分析或文档转换流程，优先沉淀到 `scripts/`。
